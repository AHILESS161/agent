# Иллюстрации принципов сервиса

Три самостоятельные иллюстрации созданы встроенным инструментом `image_gen` по общему стилевому референсу [three-gods.png](../three-gods.png). Исходное групповое изображение не изменено.

| Образ | Изображение | Точный промпт |
| --- | --- | --- |
| Фемида — честная оценка | [themis.png](themis.png) | [themis.prompt.txt](themis.prompt.txt) |
| Плутос — ценность бренда | [plutus.png](plutus.png) | [plutus.prompt.txt](plutus.prompt.txt) |
| Тюхе — осознанный выбор | [tyche.png](tyche.png) | [tyche.prompt.txt](tyche.prompt.txt) |

Каждый PNG: 1122 × 1402 px. Полная фигура на низком постаменте; тёплый мрамор, кремовый фон, тонкие золотые цифровые дуги и связи за скульптурой. Изображения используются на публичной странице `/principles` и включаются Vite в production-сборку.
