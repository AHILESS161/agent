# Архив документации

Здесь сохранены документы, полезные для истории решений, но не являющиеся
источником правды о текущем продукте.

- `history/` — аудиты, отчёты о выполненных изменениях и release notes;
- `plans/` — дореализационные спецификации, исследования и планы, которые могут
  расходиться с кодом.

Для работы с проектом используйте документы из корня `docs/`, начиная с
[`../current-state.md`](../current-state.md). Если архивный текст противоречит
коду, тестам или актуальной документации, приоритет имеют код, тесты и
`current-state.md`.
