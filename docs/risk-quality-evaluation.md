# Контроль качества подбора МКТУ и оценки риска

**Дата прогона:** 28 августа 2026 года.

Документ фиксирует воспроизводимые проверки собственных алгоритмов системы без
подмены результата красивым текстом LLM. Он не является статистической оценкой
на всём рынке: для precision/recall нужен размеченный юристами корпус реальных
заявок, противопоставлений и решений Роспатента.

## Что проверяется

Контур состоит из четырёх разных частей:

1. локальный поиск подходящих классов по актуальному справочнику МКТУ;
2. детерминированное сравнение обозначений по звучанию, написанию и словам;
3. оценка однородности конкретных товаров и услуг;
4. LLM/RAG-проверка абсолютных оснований, где каждый неблагоприятный вывод
   должен выдержать проверку цитаты и фактов дела.

Поиск карточек реестра является отдельной внешней зависимостью. Чистый
оценщик не может подтвердить, что регистрация с конкретным номером существует:
в пользовательский ответ такие сведения попадают только из результата поиска.

Эти части запускаются не параллельно. Абсолютные основания являются первым
юридическим фильтром: высокий или критический подтверждённый риск останавливает
конвейер до обращения к реестру. Низкий и средний риск пропускают обозначение к
поиску относительных оснований. Ненадёжный результат первого фильтра также
блокирует следующий этап до успешного повтора. Регрессионные тесты отдельно
проверяют, что при высоком абсолютном риске реестр не вызывается, а при низком —
вызывается.

## Контрольная матрица сходства

| Сценарий | Ожидаемое решение | Результат |
|---|---|---|
| «Юная модница» / тождественный знак, одинаковая детская одежда | критический кандидат | тождество, риск смешения |
| «Юная модница» / «Донская модница», класс 25, одежда | значимый кандидат из-за общего доминирующего слова и товаров | риск смешения |
| «Дружелюбный сосед» / «Зелёный посад», общий класс 37, но разные услуги | один номер класса не должен создавать отказ | низкий предварительный риск, смешение не установлено |
| «КОТ» / «КОТЛЕТА», общий класс 30, разные товары | короткое вхождение не является смысловым совпадением | низкий предварительный риск, смешение не установлено |
| «РЕГИСТР» / «РЕЕСТР», одинаковое ПО класса 9 | близкое написание и звучание требуют проверки | риск смешения |
| одинаковое обозначение в разных классах | точное тождество нельзя автоматически игнорировать | кандидат сохраняется для оценки юристом |
| сходные цвета или компоновка разных логотипов | техническая метрика не должна сама создавать юридический риск | изображение только ранжирует кандидатов |

Регрессионная матрица закреплена в `test_similarity.py`. В ходе прогона были
обнаружены и исправлены два дефекта:

- прежняя версия считала совпадение класса МКТУ доказательством полной
  однородности; теперь класс задаёт только направление, а высокий результат
  требует пересечения конкретных формулировок товаров и услуг;
- короткое слово внутри другого слова (`КОТ` / `КОТЛЕТА`) ошибочно давало
  смысловое сходство; теперь вхождение учитывается только для достаточно
  длинной и существенной части обозначения.

## Контроль подбора МКТУ

Локальный справочник проверяется запросами по номеру, обычным словам и
словоформам: одежда → 25, обувь → 25, кофе → 30, реклама → 35, разработка
программ → 42, ремонт бытовой техники → 37, аренда смартфонов → 38,
косметологические услуги → 44. Последний сценарий выявил разницу словоформ
«косметологические» и «косметологов»; она устранена отдельной нормализацией.

Это проверка локального резервного определителя. Основной подбор может быть
дополнен LLM, но модель не имеет права предлагать несуществующий класс и её
результат всегда остаётся на подтверждение пользователя.

## Защита от правдоподобных, но неверных юридических выводов

RAG-анализатор отклоняет вывод, если цитата отсутствует в переданном источнике,
источник не относится к конкретному знаку либо нейтральное обстоятельство
названо риском. Отдельными тестами закреплено:

- обычные слова и рекламная ассоциация не равны описательности;
- «Дружелюбный сосед» не становится описанием ремонта компьютеров только из-за
  рассуждения о «дружелюбном сервисе»;
- «Юная модница» не получает высокий абсолютный риск только из-за тезиса, что
  сочетание указывает на предполагаемого покупателя детской одежды;
- реально найденные более ранние знаки с общим сильным элементом и однородными
  товарами продолжают учитываться как относительный риск.

Поэтому ответ для проблемного обозначения должен выглядеть не как перечень
коэффициентов, а как юридическое объяснение обычному человеку:

- **итог:** насколько опасно подавать знак в текущем виде;
- **почему:** какие конкретные более ранние знаки и товары создают проблему;
- **что делать:** изменить сильный словесный элемент, сузить перечень либо
  передать конкретное совпадение юристу;
- **источник:** номер карточки и ссылка на реестр, если карточка действительно
  была получена.

## Честная оценка зрелости

Текущий контур подходит для предварительного отбора кандидатов и понятной
подготовки самостоятельного заявителя. Его нельзя продавать как замену
профессиональному заключению без оговорок.

Сильные стороны: точные и близкие написания, транслитерация, общий сильный
словесный элемент, поиск прежде всего в выбранных классах, строгие цитаты RAG,
сохранение результата при сбое внешнего сервиса.

Ограничения: смысловые переводы зависят от LLM; однородность разных классов
нельзя надёжно вывести из одного справочника; публичный реестр неполон и
нестабилен; полного обратного визуального индекса нет; метрики качества на
реальном размеченном корпусе пока отсутствуют.

До платного пилота нужен обезличенный eval-набор не менее чем из 100–200 пар,
размеченных патентным специалистом: «пропустить», «показать как кандидат»,
«высокий риск». Для него следует отдельно измерять полноту опасных совпадений,
долю ложных тревог и качество объяснений.
