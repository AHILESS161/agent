# «Регистр» — подготовка заявки на товарный знак

> **Исходный код доступен только для просмотра.** Копирование, изменение,
> распространение и использование исходного или бинарного кода запрещены без
> предварительного письменного согласия правообладателя «Регистр». Это не
> Open Source. Полные условия приведены в файле [LICENSE](LICENSE).

Помогает предпринимателю пройти понятный путь от описания обозначения до
предварительной проверки, выбора классов МКТУ, рабочего DOCX-черновика и расчёта
пошлин. Администратор получает все клиентские заявки, назначает ответственного
юриста и контролирует профессиональную проверку.

> **Система не выдаёт результаты AI за юридическое заключение
> и не подаёт заявку в Роспатент автоматически.**
> Каждое юридически значимое действие требует подтверждения специалистом.

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build
docker compose exec api alembic upgrade head
docker compose exec api python -m app.seed.init_db
```

Интерфейс: <http://localhost:3000> · API: <http://localhost:8000/docs>

Без Docker и подробности — [`docs/demo-deployment.md`](docs/demo-deployment.md).

### Сквозной сценарий для проверки

1. Войти под `client@demo.ru` и создать заявку. Обычная инициализация не создаёт
   тестовые проекты; для отдельной демонстрационной базы используйте
   `python -m app.seed.init_db --with-demo-cases`.
2. На этапе **«Загрузка»** добавить документы заявителя, выбрать вид знака и,
   если требуется, загрузить логотип или аудиозапись.
3. На этапе **«Проверка данных»** проверить все извлечённые реквизиты, описание
   обозначения и товары/услуги. Исправить ошибки, заново подобрать и подтвердить
   классы МКТУ.
4. Запустить проверку. После завершения автоматически откроется этап
   **«Анализ»** с тремя блоками: что хорошо, что может помешать и что делать.
5. На этапе **«Пошлины»** проверить расчёт и применимые льготы.
6. На этапе **«Документы»** скачать единый ZIP с заявлением, применимыми
   приложениями и памяткой. Отдельный этап **«Ответ Роспатенту»** используется,
   если ведомство пришлёт уведомление после подачи.
7. Войти администратором: клиентская заявка должна быть в общем списке. Назначить
   юриста и проверить, что у него доступны дело и тот же расчёт пошлин.

на FastAPI, адрес задаётся `VITE_API_URL`.

### Обновление базы знаний

В репозитории закреплён полный русскоязычный снимок МКТУ 13-2026 ФИПС:
45 классов и 10 122 позиции. Приложение не скачивает классификатор во время
анализа — это сохраняет воспроизводимость результатов. Для плановой
актуализации и переиндексации:

```bash
cd backend
../venv/Scripts/python -m scripts.sync_nice_classification --refresh
../venv/Scripts/python -m scripts.ingest_knowledge
```

Официальные URL, редакции, даты действия и проверки находятся в
[`backend/knowledge/sources.json`](backend/knowledge/sources.json). Подробности —
в [`docs/rag-and-legal-safety.md`](docs/rag-and-legal-safety.md).

## Ограничения

- В рабочем локальном профиле включён `FIPS_PROVIDER=rospatent_public`: он выполняет
  read-only поиск регистраций и опубликованных заявок без API-ключа через публичный
  интерфейс поисковой платформы. Это недокументированный и потому ограниченный режим.
  Для договорного официального доступа используйте `FIPS_PROVIDER=fips` и `FIPS_API_KEY`.
- Полный анализ детерминированно оценивает найденные записи, затем передаёт
  настроенной LLM максимум 10 наиболее значимых регистраций и заявок. Поиск
  сначала выполняется по ранее определённым классам МКТУ и только затем —
  контрольным широким проходом. Модель применяет критерии Правил № 482,
  поясняет риски, но не меняет числовые оценки; её ответ сохраняется в аудите.
- Правовой анализ носит предварительный характер и требует проверки
  специалистом.
- Сканированные PDF и изображения распознаются локально через Tesseract OCR
  (`rus+eng`). Обычные PDF читаются по текстовому слою, OCR включается только
  для пустых или почти пустых страниц; результат требует проверки специалистом.
- Отмеченность чекбоксов бланка из PDF определить невозможно — вид знака,
  тип приоритета и пункт пошлины заполняются только вручную.
- Паттерны извлечения проверены на типовых формах выписок ЕГРЮЛ и ЕГРИП;
  предложенные значения всё равно нужно сверить с загруженным документом.

Полный перечень — в [`docs/roadmap.md`](docs/roadmap.md).
