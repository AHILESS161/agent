## Aha moment

`[Assumption]` Первый aha — не готовый DOCX. Он возникает, когда пользователь впервые видит **конкретный риск с понятной причиной и понимает, что делать до оплаты пошлин**. Второй aha — скачиваемый пакет, где каждое ключевое поле можно проследить к подтверждённому источнику.

## Two-lane routing

```text
Qualified simple case → self-service → internal pilot review → package → filing guidance
Borderline/complex case → evidence preserved → lawyer review/representation → explicit price/SLA
```

## Moments of truth

1. Privacy explanation before upload.
2. Honest incomplete state when registry/data provider fails.
3. Full fees before payment.
4. Why a class/item is included or excluded.
5. No repeated intake when escalating to lawyer.
6. Status, deadline and next action after filing.

## B2B journey — later pilot

`[Assumption]` Historical anonymized case → import/intake → AI evidence draft → lawyer edits/approves → DOCX export → time/quality comparison → usage payment. No subscription until repeated use demonstrates ROI.

## Data Gaps

Actual dwell time, field errors, mobile behavior, abandonment reasons, aha recognition, escalation rate and support contacts.

## Red Flags

- `[Risk]` Product can technically generate a package before the business has proven the user understood and safely confirmed it.

## Yellow Flags

- `[Assumption]` Emotional journey and aha moment were not observed in interviews.
