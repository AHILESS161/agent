# Полнота правовой проверки

Сверка того, что делает система, с проверками, которые патентный
поверенный проводит перед подачей заявки на товарный знак.

Документ честный: он показывает не только покрытое, но и пробелы.

---

## ⚠️ Найденный дефект базы знаний

**Нумерация пунктов статьи 1483 ГК РФ в `knowledge/gk_rf_part4_trademarks.md`
не соответствует действующей редакции.**

| В базе знаний | Фактически в ГК РФ |
|---|---|
| п. 2 — общественные интересы и мораль | п. 2 — **государственные символы**, международные организации, клейма, награды |
| п. 3 — ложные + культурное наследие | п. 3 — ложные/вводящие в заблуждение **и** общественные интересы, гуманность, мораль |
| п. 4 — государственные символы | п. 4 — **особо ценные объекты культурного наследия** |
| — | п. 5 — вина и спиртные напитки (международный договор) |
| — | п. 7 — НМПТ и географические указания |
| — | п. 8 — фирменные наименования, коммерческие обозначения |
| — | п. 9 — произведения, имена известных лиц, промобразцы, доменные имена |
| — | п. 10 — обозначения по международным договорам |

### Почему это важно

Проверка цитат защищает от того, что **модель выдумает** норму. Она
не защищает от того, что **сама база знаний содержит ошибку**: цитата
будет дословно найдена в источнике и признана подтверждённой, а вывод
будет ссылаться на неверный пункт закона.

Это ограничение принципиальное. Достоверность выводов не может быть
выше достоверности корпуса. **Корпус требует проверки юристом.**

## Сводка

| Раздел | Покрытие |
|---|---|
| A. Заявитель | ~50 % |
| B. Абсолютные основания | ~40 % категорий, анализ в demo |
| C. Относительные основания | ~10 % |
| D. Оценка сходства | ~15 % |
| E. МКТУ | ~20 % |
| F. Поиск | ~10 %, demo |
| G. Приоритет | 0 % |
| H. Формальные требования | ~30 % |
| I. Стратегия | ~10 % |

**Вывод.** Система закрывает начало процесса — приём документа,
извлечение и подтверждение реквизитов заявителя — и имеет рабочий
контур проверяемого правового анализа. Но как инструмент полной
предрегистрационной проверки она пока покрывает меньшую часть работы
поверенного.

Наиболее заметные пробелы, влияющие на практическую ценность:

1. **Относительные основания** — п. 7, 8, 9 не покрыты вовсе, хотя
   именно конфликты с чужими правами дают большинство отказов.
2. **Однородность товаров** — без неё оценка конфликта неполна.
3. **Приобретённая различительная способность и дискламация** —
   основные практические инструменты преодоления отказа.
4. **Проверка по фирменным наименованиям** — данные ЕГРЮЛ уже
   извлекаются, источник для проверки частично доступен.
5. **Приоритет** — сроки не контролируются.
6. **Пошлины** — не рассчитываются.

## Что нужно от владельца продукта

1. **Юридическая проверка корпуса базы знаний.** Нумерация пунктов
   ст. 1483 сейчас неверна; остальной корпус не проверялся юристом.
2. **Источники данных** для поиска: реестр ТЗ, заявки, общеизвестные
   знаки, НМПТ, Мадридские регистрации.
3. **Справочник МКТУ** в машиночитаемом виде и его редакция.
4. **Методика оценки однородности** товаров и услуг, принятая в фирме.
5. **Приоритеты**: какие из пробелов закрывать первыми.
