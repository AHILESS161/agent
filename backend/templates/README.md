# Шаблоны документов

Этот каталог предназначен для хранения шаблонов документов, используемых
в системе регистрации товарных знаков.

---

## Статус MVP

В текущей версии (MVP) документы генерируются **программно** с помощью
библиотеки `python-docx` в классе `DocumentGenerator`
(`app/services/document_generator.py`). Файлы `.docx`-шаблонов в этом
каталоге не требуются для работы MVP.

Переход на `docxtpl` (шаблоны Jinja2 внутри `.docx`) предусмотрен
в следующей итерации — структура `DocumentGenerator` уже готова к этому.

---

## Требуемые шаблоны (4 документа)

### 1. Заявление на регистрацию товарного знака
**Файл**: `application_draft.docx`

Официальная форма заявления по форме, утверждённой Приказом Роспатента № 167
от 20.09.2023. Содержит:

| Поле | Источник |
|------|----------|
| Заявитель (наименование) | `client.legal_name` |
| ИНН / ОГРН | `client.inn`, `client.ogrn` |
| Юридический адрес | `client.legal_address` |
| Обозначение товарного знака | `application.mark_name` |
| Вид обозначения | `application.mark_type` |
| Перечень товаров/услуг | `application.goods_services_description` |
| Классы МКТУ | из `NiceClassSuggestion` (утверждённые) |
| Дата подачи | генерируется автоматически |
| Подпись заявителя | поле для подписи |

**Формат**: A4, Times New Roman 12pt, поля: 20/20/20/30 мм

---

### 2. Письмо клиенту о нехватке данных
**Файл**: `missing_info_letter.docx`

Официальное письмо клиенту с указанием перечня недостающих сведений или
документов, необходимых для продолжения обработки заявки.

| Поле | Источник |
|------|----------|
| Адресат | `client.legal_name`, `client.contact_email` |
| Номер заявки | `application.id` |
| Перечень недостающих пунктов | `missing_items` (список) |
| Срок предоставления | настройка (по умолчанию 14 дней) |
| Контакт менеджера | `assigned_to.full_name`, email |

**Формат**: A4, деловое письмо

---

### 3. Внутренний memo юристу
**Файл**: `legal_memo.docx`

Внутренний меморандум, направляемый юристу для проведения правовой экспертизы.

| Поле | Источник |
|------|----------|
| Адресат | `lawyer.full_name` |
| Номер заявки | `application.id` |
| Описание обозначения | `application.mark_name`, `mark_type` |
| Классы МКТУ | утверждённые классы |
| Результаты предварительного анализа | `LegalReview.summary` |
| Выявленные риски | `LegalReview.risk_level`, `blocking_issues_json` |
| Рекомендация ИИ | из агента |
| Дата | генерируется автоматически |

**Формат**: A4, внутренний документ компании

---

### 4. Шаблон доверенности
**Файл**: `power_of_attorney.docx`

Доверенность на представление интересов клиента в Роспатенте
(нотариальная или простая форма, в зависимости от типа клиента).

| Поле | Источник |
|------|----------|
| Доверитель | `client.legal_name`, реквизиты |
| Доверенное лицо | реквизиты патентного поверенного |
| Объём полномочий | фиксированный текст |
| Срок действия | 3 года (по умолчанию) |
| Место подписания | г. Москва |

**Формат**: A4, нотариальная форма

## Именование переменных (docxtpl Jinja2)

При создании `.docx` шаблонов используйте следующие имена переменных:

```
{{ client_name }}              — наименование заявителя
{{ client_inn }}               — ИНН
{{ client_ogrn }}              — ОГРН / ОГРНИП
{{ client_address }}           — юридический адрес
{{ application_id }}           — номер заявки в системе
{{ mark_name }}                — наименование обозначения
{{ mark_type_display }}        — вид обозначения (словесное / изобразительное и т.д.)
{{ nice_classes }}             — список классов МКТУ
{{ goods_services_list }}      — перечень товаров/услуг
{{ missing_items }}            — список недостающих данных
{{ lawyer_name }}              — ФИО юриста
{{ manager_name }}             — ФИО менеджера
{{ risk_level_display }}       — уровень риска
{{ legal_summary }}            — краткое заключение правовой экспертизы
{{ today_date }}               — текущая дата (ДД.ММ.ГГГГ)
{{ deadline_date }}            — крайний срок ответа
```

---

## Создание шаблонов

1. Создайте документ в Microsoft Word или LibreOffice Writer
2. Вставьте переменные в формате `{{ variable_name }}`
3. Сохраните как `.docx`
4. Поместите файл в этот каталог
