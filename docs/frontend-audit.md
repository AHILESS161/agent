# Аудит frontend

Состояние на момент начала работ и результат.

---

## 1. Что было найдено

**Слоя данных не существовало.** Не «частично подключён» — ноль запросов
к API:

- `client/src/lib/queryClient.ts:3` → `API_BASE = "."` (same-origin);
- `server/routes.ts` → `registerRoutes()` **не регистрировал ни одного
  маршрута** — пустой скаффолд Replit;
- все 10 страниц импортировали `lib/mock-data.ts` (425 строк);
- `apiRequest` и `getQueryFn` были определены и **не использовались нигде**.

**Авторизация была фиктивной.** `lib/auth.tsx:18`:

```ts
const login = useCallback((email: string, _password: string) => {
  const found = getUser(email);   // пароль игнорируется полностью
```

Любой пароль подходил, токена не было, сессия жила в памяти React
и терялась при перезагрузке страницы.

**Express-обёртка была мёртвым грузом.** `express`, `passport`,
`drizzle-orm`, `better-sqlite3`, `express-session`, `ws` числились
в зависимостях и не использовались.

**Отсутствовали ключевые экраны:** загрузка файлов, подтверждение полей,
отчёт о рисках. Кнопка «Скачать DOCX» (`application-detail.tsx:597`)
не имела обработчика.

**Не было маркировки demo-режима и предупреждения об ограничениях AI.**

**Расхождения с backend:**

| Что | Frontend | Backend |
|---|---|---|
| Поле имени пользователя | `fullName` | `full_name` |
| Роли | `admin/lawyer/client` | `admin/lawyer/manager/client` |
| Статусы дел | свой словарь из 18 | свой словарь из 18, пересечение — 2 |

Первое роняло `TopBar` в белый экран сразу после входа. Третье приводило
к пустым статусам в таблице заявок.

## 2. Что сделано

### Убрано

- каталоги `server/`, `script/`, файл `drizzle.config.ts`;
- 19 неиспользуемых пакетов из `package.json`.

### Добавлено

| Файл | Назначение |
|---|---|
| `lib/api.ts` | клиент API с JWT, типизированные DTO, обработка 401/403/5xx |
| `lib/use-cases.ts` | хуки дел и клиентов с нормализацией snake_case → camelCase |
| `lib/use-unread-count.ts` | счётчик уведомлений из API |
| `components/source-documents-tab.tsx` | загрузка, список, скачивание, запуск извлечения |
| `components/field-confirmation-tab.tsx` | сверка полей и решения специалиста |
| `components/ai-disclaimer.tsx` | предупреждение об ограничениях AI |
| `components/demo-data-notice.tsx` | пометка экранов на демо-данных |

### Переработано

- `lib/auth.tsx` — настоящий JWT, токен в `localStorage`, восстановление
  сессии, возврат ко входу при 401;
- `pages/login.tsx` — асинхронный вход, состояние отправки, текст ошибки,
  предупреждение о демо-стенде;
- `pages/applications-list.tsx`, `pages/application-detail.tsx` —
  реальные данные, состояния загрузки/ошибки/повтора;
- `shared/schema.ts` — статусы выровнены по машине состояний backend;
- `vite.config.ts` — прокси на FastAPI, `allowedHosts` для туннеля;
- `tsconfig.json` — добавлен `target: ES2020` (без него `tsc` падал).

## 3. Текущее состояние

### Работает на реальных данных

вход · список заявок · шапка карточки дела · вкладка «Общие сведения» ·
вкладка «Исходные документы» · вкладка «Сверка полей» · счётчик уведомлений

### Читает демонстрационные данные

Вкладки: полнота данных, правовой анализ, классы МКТУ, конфликты,
рекомендации, документы, история.
Страницы: дашборд, клиенты, аудит, администрирование, уведомления.

**Каждая помечена баннером** `DemoDataNotice` с текстом, что раздел
не подключён к БД и показывает пример оформления.
