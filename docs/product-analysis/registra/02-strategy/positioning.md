# Positioning: «Регистра»

**Дата:** 28 августа 2026 года  
**Framework:** April Dunford  
**Confidence:** Low–Medium; untested with customers

## 1. Competitive alternatives

1. Самостоятельная подача через Роспатент/Госуслуги/МСП.РФ.
2. Бесплатный поиск + универсальная LLM + шаблоны.
3. Online Patent, Brandside, ЕДРИД и другие hybrid services.
4. Патентный поверенный/юрфирма.
5. Отложить регистрацию или ничего не делать.

`[Data]` Эти альтернативы существуют; `[Data gap]` их реальная доля в выбранном beachhead неизвестна.

## 2. Unique attributes — target state

- Source→fact→conclusion traceability instead of one success percentage.
- Business-language intake translated into bounded МКТУ with exclusions.
- Field provenance and confirmation before document generation.
- Reproducible DOCX/ZIP evidence package.
- Explicit simple/borderline/complex routing.
- Human review without repeated intake.
- Case status and response continuity.

`[Data/Assumption]` Часть возможностей уже может существовать в репозитории; их production readiness проверяется в Phase 6. Уникальность относительно каждого конкурента требует mystery shopping.

## 3. Attribute → value

| Attribute | Value | Why customer may care |
|---|---|---|
| Traceability | проверяемый вывод | снижает black-box distrust |
| Guided МКТУ | понятный scope | уменьшает риск бесполезной охраны |
| Provenance/confirmation | контроль данных | предупреждает document errors |
| Filing package | готовое действие | экономит изучение формы |
| Routing/human review | подходящий уровень помощи | не маскирует complexity |
| Lifecycle | один источник статуса | снижает deadline anxiety |

Все value links — `[Assumption based on secondary research]`.

## 4. Target market

`[Assumption]` Российский ИП/самозанятый/микробизнес, уже использующий собственный товарный/private-label бренд, с одним простым обозначением и намерением подать в ближайшие 30 дней.

Не таргетировать в launch: сложные/международные дела, «идея без использования», отсутствие собственного бренда, ожидание гарантии.

## 5. Market category

**Recommended category:** новая подкатегория существующего рынка — **«сервис проверяемой подготовки заявки на товарный знак»**.

Не создавать широкую категорию «AI legaltech». Не заявлять «онлайн-регистрация» как отличие: это уже стандарт.

## Positioning statement

> Для владельцев уже используемых брендов, которые хотят подать заявку самостоятельно, но не готовы рисковать пошлинами из-за непонятного поиска и МКТУ, «Регистра» — сервис проверяемой подготовки заявки. В отличие от бесплатной формы или black-box AI, он показывает основания каждого риска, формирует редактируемый комплект и подключает юриста в пограничном случае.

## Onliness test

`[Target claim, not yet proven]` Единственный сервис для самостоятельного заявителя, где анализ, происхождение данных, МКТУ, документы и human fallback образуют один проверяемый workflow.

До внешнего использования слова «единственный» провести feature mystery shopping всех прямых конкурентов.

## Data Gaps

Customer language, category comprehension, comparative feature proof, value priority and conversion of evidence-first positioning.

## Red Flags

- `[Risk]` «Единственный» нельзя публиковать без полной конкурентной проверки.

## Yellow Flags

- `[Assumption]` Выбранная category label может звучать юридически и сложно для B2C.
