# Дизайн 03 и инструменты

Третья версия дизайна перенесена из отдельного прототипа в основной React-интерфейс. Изменены клиентская оболочка, вход и регистрация, обзор заявок и клиентские экраны. Палитра и шрифты заданы в `frontend/client/src/styles/registr-v3.css`; административная оболочка сохраняет свою тему. Изображение фронтона — оригинальный сгенерированный ресурс из дизайн-прототипа, хранится локально в `frontend/client/src/assets/pediment.png`.

## Маршруты

- `#/services?tool=reply` — ответ Роспатенту.
- `#/services?tool=reply&application=123` — ответ по конкретной доступной пользователю заявке.
- `#/services?tool=compare` — сравнение словесных обозначений.

Страница доступна из меню клиентского кабинета, карточек на главной и меню рабочего кабинета. Вход и серверная проверка доступа сохраняются. При одной заявке она выбирается автоматически; при нескольких пользователь выбирает заявку. Список поддерживает страницы, а прямая ссылка загружает указанную заявку отдельно.

## Подготовка ответа

Используется существующий `OfficeActionResponse` и текущие API `office-actions`/`source-documents`. Обязателен файл уведомления. На виду — загрузка и необязательное поле позиции; срок и подробные доказательства раскрываются дополнительно. Кнопка подготовки сама сохраняет факты. Результат формируется существующим серверным процессом и скачивается в DOCX. Автоматической отправки в Роспатент нет.

Переключение вкладок инструментов сохраняет введённые данные. Во время сохранения, загрузки и генерации блокируется смена заявки. Запросы ручного и автоматического сохранения сериализованы; при ошибке можно повторить сохранение. Загрузка переписки имеет состояние ошибки и повтор.

## Сравнение

Два обязательных названия, до 120 Unicode-символов каждое; товары и услуги можно добавить как заметку. Сравнение выполняется в браузере. Проверяются буквальное совпадение, совпадение без регистра и пробелов, общие слова; различия выделяются. Кириллица и латиница не приравниваются. Результат можно скопировать и скачать в TXT. После изменения исходных данных экспорт блокируется до повторного сравнения.

Это техническое сравнение текста: оно не заменяет оценку сходства до степени смешения, не анализирует изображения и однородность товаров, не присваивает проценты сходства.

## Начало заявки

У клиента первоначально показаны название и деятельность. Выбор и загрузка логотипа доступны по ссылке «У меня логотип или другой вид знака». Создание дела, автосохранение, OCR и переход к подбору товаров используют существующую реализацию.

## Проверки

Из `frontend`: `npm run check`, `npm run check:comparison`, `npm run build`.
Тест сравнения компилирует производственную TypeScript-утилиту в памяти через существующий пакет TypeScript и работает в Node 20+, используемом CI и Docker.

Изменения относятся к исходному коду и локальной сборке. Публикация основного приложения выполняется отдельно через штатный процесс развёртывания.
