# PowerPoint-презентации «Регистра»

- `registra-investor.pptx` — 12 слайдов для инвесторов.
- `registra-client.pptx` — 8 слайдов для клиентов.
- `investor-contact-sheet.png` и `client-contact-sheet.png` — визуальные листы контроля всей презентации.
- `investor-preview/` и `client-preview/` — PNG-превью отдельных слайдов.

Все слайды используют редактируемые PowerPoint-тексты и фигуры. В каждый слайд встроен переход Fade, Push или Wipe. Финансовые показатели синхронизированы с финальной Stage A моделью.
