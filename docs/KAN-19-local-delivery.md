## Что изменилось для клиента

Путь состоит из трёх этапов: **знак и товары → результат проверки → подготовка к подаче**. Для предварительной проверки достаточно обозначения, описания деятельности и явного выбора товаров. Реквизиты, подписант, дата, доверенность и приложения доступны при подготовке пакета. Требования к готовности самого пакета сохранены.

Предложенные классы не включаются автоматически. По умолчанию предлагается конкретный перечень по деятельности; для полного класса сначала показываются состав, число позиций и дополнительная пошлина. Заголовок заявки и список используют одно фактическое состояние, включая очередь, ошибку и неполную проверку. Восстановление этапа из адреса браузера исправлено. Ошибка загрузки результата больше не выдаётся за отсутствие анализа.

## Проверка

Локальное окружение: Windows, SQLite, Python из `.venv`, точные версии frontend из `package-lock.json`. Демонстрационные LLM и реестр. Данные рабочей базы не копировались. `uvloop` не устанавливался на Windows; серверный Linux/PostgreSQL здесь не воспроизводился.

- Полный прогон: **946 тестов прошли** за 8 минут 14 секунд.
- Целевые прогоны: **31 и 83 теста прошли**, включая экспорт решений, аудит, классы, пакет документов и устаревание результата. После последних правок повторно прошли **20 тестов** решений специалиста, статусов и управления классами.
- TypeScript: проверка прошла; production-сборка интерфейса прошла. У сборки остаётся предупреждение о размере основного JS-файла; разделение загрузки не входило в эти исправления.
- Перенос заявителя (KAN-46): в браузере проверены отсутствие реквизитов на старте и при проверке знака, открытие формы по кнопке после результата, включая неполную проверку, сохранение заявителя и переход к пошлинам. Через API проверено, что раннее редактирование знака не меняет заявителя и подписанта, а подтверждение формы подачи сохраняет их. Временная тестовая заявка удалена.

Автотесты подтверждают поведение кода и обработку ответов. Они не заменяют юридическую оценку, полноту живого реестра, работу почты или тест удобства с реальными клиентами.
